# 快速开始

## 安装

::: code-group

```sh [npm]
npm add -D releaseasy
```

```sh [pnpm]
pnpm add -D releaseasy
```

```sh [yarn]
yarn add -D releaseasy
```

```sh [bun]
bun add -D releaseasy
```

:::

## 安装向导

releaseasy 附带一个命令行设置向导，可以帮助你快速生成基本的配置文件。安装后，通过运行以下命令启动向导：

::: code-group

```sh [npm]
npx releaseasy init
```

```sh [pnpm]
pnpm releaseasy init
```

```sh [yarn]
yarn releaseasy init
```

```sh [bun]
bun releaseasy init
```

:::
