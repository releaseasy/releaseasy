# Changelog

Generating a changelog is a core feature of releaseasy. Under the hood, it is powered by the flexible and customizable Git changelog generation tool [git-cliff](https://github.com/orhun/git-cliff).

## Enable changelog generation

releaseasy has git-cliff built in, and it can be configured via `git.changelog` in the configuration file.

```js{6-10}
/** @type { import('releaseasy').UserConfig } */
export default {
  increments: ["patch", "minor", "major"],
  distTags: ["latest", "next"],
  git: {
    changelog: {
      output: "CHANGELOG.md",
      configFile: "cliff.toml",
      args: "--tag ${version}",
    },
  },
};

```

::: tip
If you want to disable changelog generation, you can set `changelog` to `false`.
:::

## Changelog templates

git-cliff has many built-in templates for very popular changelog formats (specifications). You can view [examples](https://git-cliff.org/docs/templating/examples) of the results generated by different templates in the git-cliff documentation. You can also find [template files](https://github.com/orhun/git-cliff/tree/main/examples) directly in the git-cliff repository. Then choose the format you like, copy it into the `cliff.toml` configuration file, run `pnpm releaseasy` to generate the changelog, and preview the generated changelog.

> [!TIP]
> It is recommended to generate it with the releaseasy init command.
